# מדריך התקנת AutoCAD לתלמידים

אתר סטטי (GitHub Pages) שמסביר שלב אחר שלב איך להתקין AutoCAD ב-Windows ולהיכנס אליו, לתלמידים שכבר יש להם חשבון Autodesk עם רישיון מבית הספר.

- `index.html`, `style.css`, `script.js` – האתר
- `images/` – איורי המסכים
- `mockups/` – המקור של האיורים. אחרי שינוי ב-`mockups/mockups.html` מריצים `node mockups/render.js` כדי ליצור מחדש את התמונות.
  אפשר גם פשוט להחליף כל תמונה ב-`images/` בצילום מסך אמיתי עם אותו שם קובץ.
